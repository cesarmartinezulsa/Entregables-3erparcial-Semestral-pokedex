# Pokédex PWA

Pokédex de la primera generación (#001 a #151) donde cada Pokémon se captura escaneando un código QR.

## Autores

- Caleb Aguilar León
- César Martínez Ruiz

## Cómo ejecutar

Abre `index.html` en el navegador (se recomienda la vista móvil de las herramientas de desarrollo). Necesita internet para cargar Tailwind CSS, la fuente y las imágenes.

## Estructura

```
pokedex/
├── index.html
└── js/
    ├── config.js   configuración de Tailwind
    ├── datos.js    datos y constantes
    └── app.js      lógica de la interfaz
```
